# Dashboard Readme  
## Part 2 - Data Visualization & Insights  

Using the enhanced dataset, I noticed that we have a larger audience of females than males, so we could concentrate on getting more men interested in our projects. Newsletter subscriptions are more popular than actual attendance across both genders, suggesting an opportunity to use marketing—through newsletters, magazines, or similar channels—to increase engagement.  

I calculated the attendance rate as `Attended / (Registered + Attended)` to examine engagement. Despite only having 27 participants, **“Eleva tu foundraising con ChatGPT II”** Project was the most well-liked and had a 100% attendance rate. **“Impulsa tu actividad con IA”**, the next most interesting project, had an attendance rate of 75%.  

Finally, more people attended workshops than Propel events, suggesting that future campaigns could prioritize workshop formats to maximize participation.
